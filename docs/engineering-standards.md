# Engineering Standards

**Repository category:** Application

**Current status:** Public application; implementation maturity is documented in the README

This repository follows the profile baseline: reproducible setup, explicit architecture boundaries, secure environment-based configuration, tests for important behavior, CI checks, dependency maintenance, documentation of limitations, and changelog discipline. The repository category is part of the contract: archival and research work must not imply production support, while active products must document deployment and operational assumptions.

See the root README.md, CONTRIBUTING.md, SECURITY.md, and CHANGELOG.md for the project-specific implementation of this baseline.
